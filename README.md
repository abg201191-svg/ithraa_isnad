# لياقة أشواق

موقع تمارين منزلية بالعربية (RTL) في ملف HTML واحد: 8 أسابيع، 4 جلسات أسبوعياً، حتى 40 دقيقة، بدمبلات فقط (وحبال/سجادة/كرسي اختيارية)، بجهد خفيف وتركيز على استقامة الكتفين والرقبة والورك.

## المحتوى
- **الجدول**: الأسابيع والأيام، وكل جلسة 4 مراحل: إحماء ← تمارين ← حرق بلا قفز ← تهدئة واستقامة.
- **سجلّي**: التقدّم، أوزان الدمبلات (تنتقل تلقائياً بين الأيام)، نبض الصباح مع تفسيره، وقياسات الأسبوع.
- **أدواتي**: عدّاد النبض، مناطق النبض، البروتين، شدة الجهد، النوم.
- **المرجع**: البرنامج، 20 موضوع أدلة بدرجات قوة ومصادر، الاستقامة، الصحة اليومية، الأمان.
- الحفظ محلياً في المتصفح (localStorage) مع نسخة احتياطية يدوية من الإعدادات. وعند فتح الصفحة داخل claude.ai يُضاف حفظ سحابي اختياري (قدرة `db` + `user`)، ويختفي ذكره تماماً في النسخة المستقلة.

## النشر على GitHub Pages (يفتح على سفاري مباشرة)
`index.html` في جذر المستودع صفحة مستقلة كاملة (doctype وترميز وviewport وأيقونة وmanifest)، فلا تحتاج بناءً ولا خادماً.
1. اضغطي **Merge** على طلب الدمج لتصير الملفات في `main`.
2. من المستودع: **Settings ← Pages ← Source: Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة أو اثنتين يظهر الرابط في أعلى صفحة Pages.

على آيفون: افتحي الرابط في سفاري، ثم زر المشاركة ← «إضافة إلى الشاشة الرئيسية» ليفتح كتطبيق، وهذا يقلّل خطر مسح سفاري لبيانات الموقع إن لم تُستعمل أسبوعاً كاملاً.
الحفظ في هذه النسخة محلي على الجهاز فقط (لا حساب ولا خادم).

## البناء
`index.html` هو الناتج النهائي. المصادر:

| الملف | الدور |
|---|---|
| `data.js` | الأسابيع والتمارين والأيام والإحماء والتهدئة والأدلة والعبارات |
| `app1.js` | الحالة والحسابات والمؤقّت |
| `core2.js` | النبض والأدوات والحفظ السحابي والدمج |
| `app2.js` | بطاقات اليوم والتمارين |
| `views.js` | سجلّي وأدواتي والمرجع |
| `app3.js` | العرض والأحداث والتشغيل |
| `sem.css` `pal.css` `comp.css` | الأنماط |

```bash
python3 build.py && node --check all.js   # يعيد توليد index.html من المصادر
```

## الاختبارات (Playwright)
```bash
npm i -g playwright && npx playwright install chromium
NODE_PATH=$(npm root -g) node tests/test17.js   # يمرّ على الأسابيع الثمانية × الأيام الأربعة وكل بطاقة وبديل
NODE_PATH=$(npm root -g) node tests/test19.js   # لا تمرير أفقي من 320 إلى 430 (فاتح وداكن)
NODE_PATH=$(npm root -g) node tests/test20.js   # الصفحة المستقلة عبر http بمحاكاة آيفون: الترميز والجوال والحفظ وغياب Claude
node tests/audit1.js                              # فحص بيانات التمارين والمدد (يقرأ data.js)
```
(تُشغَّل الاختبارات من جذر المشروع.)

## ملاحظة علمية
كل موضوع في «المرجع» يذكر قوة دليله بصراحة (قوي / متوسط / محدود / منطقي)، وما لم أجد له دراسة مباشرة مذكور كذلك. الموقع ليس تشخيصاً ولا بديلاً عن طبيبة أو أخصائية علاج طبيعي.
